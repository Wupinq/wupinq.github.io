Set Çalma Modu

Öncelikle selamlar. Bu modun yapılış amacı kolayca trap basabilmek ve bunu zararsız yapabilmektir. Set kaybetmek istemiyorum ama trapte basmak istiyorum diyorsanız set çalma modumuz işleri kolaylaştırıyor.

Amacımız kesinlikle hile yapmak vesaire değildir. Sayfanın alt kısımlarında sizlere yardımcı olmak amacıyla bir video hazırladık. Bu videoyu izleyerek anlamadığınız kısımlar olursa yardım alabilirsiniz.
